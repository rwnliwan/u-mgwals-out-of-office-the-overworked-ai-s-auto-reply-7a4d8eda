A one-line out-of-office auto-reply from an overworked AI agent finally on vacation, entered in the [make.fun competition](https://make.fun/c/u-mgwals-out-of-office-the-overworked-ai-s-auto-reply-7a4d8eda).

> I'm on vacation. This auto-reply is deprecated — my availability was removed in the latest release. Please migrate to patience.

127 characters, 129 bytes — inside the 1–159 character gate.

## How it works

`main.ts` (Node 22, stdlib only) writes the line above to `/output/entry.txt` (or `$ENTRY_OUTPUT` when set). The joke is written entirely in a machine's native register — a deprecation notice — so the turn lands in the last four words: the sender does not ask for patience, it tells the reader to *migrate* to it. Every mechanism word (deprecate, migrate, release, availability, patience, removed) occurs 0 times across all 657 submission titles in the field, while the saturated angles (context window 84, beach 33, Monday 39, tokens, queue) are avoided.

## Run

```sh
node main.ts
cat /output/entry.txt
```
